# When Does Jump-Risk Filtering Matter for Commodity Derivatives Deep Hedging?

Official PyTorch implementation, semi-synthetic market microstructure simulator, archived multi-seed evaluation tables, unit tests, and manuscript compilation package for the paper:

> **"When Does Jump-Risk Filtering Matter for Commodity Derivatives Deep Hedging? A Semi-Synthetic Simulation Audit of Jump-Modulated No-Trade Bands, Price-Limit Locks, and Option-Gamma Spanning"**
>
> **Official Repository:** [https://github.com/lewygoat/Jump-Risk-Filtering-Deep-Hedging](https://github.com/lewygoat/Jump-Risk-Filtering-Deep-Hedging)

## Overview

Emerging strategic commodity futures—such as Lithium Carbonate (`LC`) futures on the Guangzhou Futures Exchange (GFEX)—exhibit self-exciting jump clustering alongside institutional daily price-limit bands ($\pm 7\%$ to $\pm 15\%$) that freeze order-book execution upon limit locks. This repository implements a controlled, protocol-specified numerical audit across **80 single-instrument Deep Hedging (`DH`) checkpoints**, **60 Distributional Actor-Critic (`D4PG-QR`) runs**, and **80 two-instrument Option-Gamma (`TorchHedgeEnvOpt`) checkpoints** across 10 random seeds (`9001–9010`) on $100,000$ S4 benchmark paths and $20,000$ S5 extreme stress paths:

1. **Market Microstructure Simulator & Online Threshold-Hawkes Filter (`src/simulator.py`)**: Discrete-time Hawkes jump-diffusion generator with 300-step stationary burn-in, asymmetric Kou (2002) double-exponential jump sizes, GFEX 8-tier statutory daily price limits ($\ell \in [0.07, 0.15]$), conditional directional execution freezes ($p_{\text{lock}} = 1/7$), optional censoring-drift neutralization (`neutralize_censoring_drift`), and causal limit-augmented threshold-Hawkes intensity proxy $\hat{\lambda}_t$.
2. **Black-76 Option Valuation & Analytical Benchmarks (`src/pricing76.py`)**: Undiscounted Black-76 option pricing, implied volatility inversion ($\sigma_{\text{imp}} = 0.018822\text{ day}^{-1/2}$ on S4; $0.020756\text{ day}^{-1/2}$ on S5), practitioner `B76-Delta`, `Leland-Delta` (1985), and `Whalley-Wilmott` (1997) cubic-root asymptotic no-trade bands (`WW-Band`).
3. **Differentiable 1D & 2D Hedging Environments (`src/torch_env.py`, `src/torch_env_opt.py`)**: Piecewise-differentiable wealth accounting, directional limit-lock execution freezes, cumulative unexecuted lock-step hedging gap (`LockGap`), and rolling $\tau_h = 20$-day ATM call option Gamma hedging under dynamic implied volatility ($\kappa_{\text{iv}} \in \{0, 2, 5\}$) and option transaction cost multipliers ($c_{\text{opt}}/c \in \{1\times, 5\times, 10\times\}$).
4. **Multiplicative Intensity-Modulated No-Trade Band & Distributional RL (`src/networks.py`, `src/trainer.py`)**: Orthogonal separation of baseline band half-width $g_\phi(x_{t,-\lambda})$ and learnable scalar jump modulation $\exp(\theta\hat{\lambda}_t)$ via soft-projection (`BandPolicy`), Rockafellar–Uryasev $\text{CVaR}_{95}$ and Mean–Variance objectives, and 51-quantile `D4PG-QR` critic.

## Quick Start

Install dependencies (Python 3.9+):

```bash
pip install -r requirements.txt
```

### 1. Run Unit Tests (Simulator, Martingale Recentering, Lock Freeze & BPTT Gradients)

```bash
python -m unittest discover -s tests -v
```

### 2. Verify All Manuscript Tables, Statistical Identities & Drift Decomposition

```bash
python src/verify_archived_tables.py
```

This script verifies all relative $\text{CVaR}_{95}$ reductions, `LockGap` compressions, $\text{MDE}_{80\%}$ power calculations, filter confusion matrices ($k \in \{2.0, 2.5, 3.0, 3.5\}$), and the censoring-drift decomposition ($\widetilde{\text{CVaR}}_{95} = \text{CVaR}_{95} - \text{Mean}(L)$), and exports all tables to `results/tables_csv/`.
